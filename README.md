# PlaySense 🎮🧠

**PlaySense** is an AI-powered desktop companion for PC gameplay. It captures your current screen, optional OBS replay clips, and typed or spoken questions to provide real-time, spoiler-controlled gameplay help.

> Early MVP — actively evolving.

---

## ✨ Features

- 🎮 Gameplay-aware AI assistance
- 🖼️ Screenshot analysis
- 🎥 OBS Replay Buffer integration
- 🎙️ Voice questions
- 🔊 Optional AI voiceover responses
- 🧭 Spoiler-control levels
- ⚡ Custom activation hotkey
- 🤖 Multiple AI provider support:
  - Google Gemini
  - OpenAI
  - OpenRouter
  - Ollama / local models
  - Custom OpenAI-compatible APIs
- 🌙 Modern dark UI
- 🔒 No game memory injection
